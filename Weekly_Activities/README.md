# Weekly Activities Portfolio – Software Development

## Introduction

This folder contains my weekly consolidate activities completed during the CS73 Software Development module, covering Unit 3 to Unit 10. These activities helped me develop my understanding of Python programming and practise different programming concepts.

Each unit focuses on a different topic, including mathematical operations, variables, data types, inventory management, code commenting, built-in libraries, functions, loops, recursion and GUI development.

I have included the Python code, outputs and explanations for the activities to show how I applied the concepts covered in each unit. These practical tasks helped me improve my coding skills, understand how programs work and gain experience in solving problems using Python.

The weekly activities also provided a foundation for developing my final Task Management System project.
